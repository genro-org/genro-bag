# genro-bag 0.28.0

Breaking ingestion API coordinated with @genrojs/bag 0.11.0 (issue #69).

- Constructors and modern fill methods accept native dicts/lists, with recursive
  conversion by default, literal labels, padded list labels and shared leaves.
- TYTX readers accept ordinary JSON, typed containers and explicitly marked Bags.
  Modern from_json is a deprecated alias. Explicit legacy codecs are retained.
- Typed leaf values survive Python/JS conversion; Bag subtype metadata is preserved.
- Resolver signatures remain verified recursively. Legacy XML adapters forward
  signing, expiry and indentation options, including nested nodes/attributes.
- Eager/reactive refresh and timer options are removed. Resolvers remain synchronous
  in Python, preserving the 0.27.0 contracts for cache, events and parameter preparation.
- Requires genro-toolbox >=0.18.0, genro-tytx >=0.16.2 and httpx >=0.27.0.

All dependents must read the [migration note](../migrations/next-ingestion-api.md)
and update constructor, reader, list-path and refresh calls as applicable.
