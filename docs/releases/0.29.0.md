# genro-bag 0.29.0

Breaking resolver parameter contract, coordinated with @genrojs/bag 0.12.0
(issues #74 and #75).

- Resolver inputs are the parameters declared at construction. Undeclared node
  attributes, such as UI metadata, never reach `load()` and never invalidate the
  cache. This rule held already in Python; it is now covered by contract tests.
- Read-time kwargs (`get_item(path, **kwargs)`, `node.get_value(**kwargs)`,
  `resolver(**kwargs)`, `bag['path?x=1']`) are a one-off read: the result is not
  cached, `node.attr` is untouched and no event is emitted.
- `set_attr` is the only permanent change of a resolver parameter.

Code that relied on a read-time kwarg being written into `node.attr` must call
`set_attr` before reading. See [BREAKING_CHANGES.md](../../BREAKING_CHANGES.md).
